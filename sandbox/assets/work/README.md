# The work's images

Website v3 (website-v3.html) and the v2 case studies (case-*-v2.html) show the studio's real work from this folder. Until a file is here its slot shows a placeholder in the project's colour that names the file it is waiting for, so dropping a file in is all it takes. No code changes needed.

- One folder per project, named as below.
- Each image may be .webp (preferred), .jpg or .png.
- cover is the lead image: used on the home page and as the case study's full-screen top. Landscape, about 2400 × 1500.
- Case-study figures: about 2400px wide, in the shape noted.
